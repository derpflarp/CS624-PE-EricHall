# Input

The application uses a local user image and predefined profile information, including a name, occupation, and short description. These values are displayed using React Native components. No user input is required because the profile information is stored directly in the application.

# Process

The application uses React Native's View, Image, and Text components to construct a profile card. A StyleSheet defines the card's appearance, including its background color, borders, rounded corners, and spacing. Flexbox properties center the card and its contents. The user image appears inside a circular container, while text styling controls font size, weight, alignment, and spacing. The profile information is organized vertically to keep the layout readable.

# Output

The application displays a blue profile card with a centered user icon, the name John Doe, an underlined occupation, and a short biography. The completed card demonstrates how React Native styling properties can organize and present profile information in a mobile application.

# Input

The HelloWorld appl doesn't require the user to enter any information. Instead, the input consists of three predefined text values stored directly in the app's source code. These values represent my name, degree program, and school. The app uses these fixed values whenever it starts.

# Process

The app uses React Native to create and display its interface. A View component serves as the main container while three Text components display the individual values. The StyleSheet defines the visual appearance of the app, including its yellow background, black text, and centered alignment. React Native renders these components according to the styling rules.

# Output

The output is a simple screen with a yellow background and three lines of centered text displaying my name, MSCS, and STC. The app demonstrates how React Native components and styling can present information consistently without requiring user interaction.
